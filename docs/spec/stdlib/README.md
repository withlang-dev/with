# Standard library

Specification sections and design documents for `std.*`, kept next to the
language specification. The numbered files are sections moved out of the
specification's chapters by heading; their numbers are unchanged and the
chapter files point here. The specification does not catalogue `lib/std`
(D48): a library is documented by its source, and adding one is not a
language change.
