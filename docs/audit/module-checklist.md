## Scope

This checklist treats each tracked production `.w` compilation unit as a module. It includes compiler, runtime, build, standard-library, test-support, and repository-tool modules. Test fixtures, examples, specifications, and documentation are audited through the coverage, harness, and specification targets rather than counted as implementation modules.

A module is checked only after the primary agent has examined its complete source,
traced every applicable audit target, and independently rerun or inspected every
retained finding and negative control. Subagent review, merely reading selected
functions, touching a module from one result, or obtaining a green build does not
complete the module.
